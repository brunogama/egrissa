# ADR 0003: Fail closed by default
**Status:** Accepted

## Context
This decision protects the runtime's correctness, replaceability, or security boundary.

## Decision
Default to ProhibitDirect; direct access must be explicitly eligible.

## Drivers
Determinism, explicit semantics, testability, provider/transport independence, failure containment.

## Alternatives
Implicit heuristics, provider-specific branching, or collapsing the concern into transport code. Rejected because they weaken auditability and invariants.

## Consequences
More explicit types/state/tests; less accidental coupling.

## Constraint
Later milestones may supersede this only through a new ADR.

## Testing
Add positive and negative tests proving the decision, including stale/failure paths where applicable.

## Revisit
Only with production evidence of a legitimate blocked use case.
