# ADR 0026: Route intelligence ranks immutable scoped facts

**Status:** Accepted

## Context

The planner filters routes against topology, availability, capability, isolation, and policy requirements. M7 adds route preference from observed reliability, latency, cooldown, cost, and destination-specific evidence. Folding those facts into endpoint health would let a rejection from one destination poison an endpoint for every destination.

## Decision

`route-core::intelligence` owns immutable `RouteScoreInput` values and produces a `RouteDecisionRecord`. Each score input identifies a topology and static rank. It carries only endpoint, upstream, or transport reliability facts. Destination evidence is a separate value keyed by `DestinationKey`.

The scorer adds the reliability shortfall, observed latency in microseconds, cost, and matching destination penalties with saturating arithmetic. Static rank and topology provide deterministic tie-breaking rather than score weights.
The scorer applies destination evidence only when its key matches the request destination. It never changes endpoint health or reliability. An active cooldown produces an excluded candidate with its expiry and evidence IDs.

`DeterministicPlanner::plan_with_decision` first applies the existing hard eligibility filters. It then passes the eligible candidates to the scorer and returns both the selected `RoutePlan` and the decision record. `RoutePlanner::plan` retains the existing selection behavior.

`SelectionPolicy::Deterministic` is the default. `AdaptiveWithinEqualScore` may use an injected chooser only within a group that shares the total penalty and static rank. An invalid adaptive choice uses the deterministic first candidate and records the fallback.

## Consequences

Callers can inspect the facts and evidence behind a route decision without duplicating planner eligibility. Observation and health projection stay in `observation-core`. Destination-specific evidence cannot globally disable an endpoint.

## Testing

Run `cargo test -p route-core --test route_intelligence` for deterministic ranking, scoped destination evidence, cooldown exclusions, adaptive fallback, planner integration, and input-order property coverage.
