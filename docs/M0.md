# M0 — Semantic Kernel

## Goal

Prove the domain semantics before adding network complexity.

## Build

Three Rust crates:

- `egress-core`
- `identity-core`
- `route-core`

## egress-core

Own:
- typed IDs
- `EgressRequest`
- `EgressPolicy`
- capability model
- common decisions/errors

## identity-core

Own:
- `NetworkIdentity`
- identity generation
- continuity (`Preserved`, `Changed`, `Unknown`)
- lifecycle

## route-core

Own:
- explicit supported topologies
- immutable `RoutePlan`
- route generation
- deterministic candidate filtering/ranking
- injected candidate chooser
- route lifecycle

## Explicitly excluded

Do not implement:
- Tokio
- sockets
- SOCKS5
- HTTP CONNECT
- MASQUE
- QUIC
- DNS
- provider APIs
- credentials
- databases
- HTTP status interpretation
- production verification probes

## Exit gate

M0 is complete only when the semantic invariants are executable tests and the entire workspace passes fmt, clippy and tests.

After M0, the next milestone is a fake end-to-end runtime. A real SOCKS5 adapter comes only after that.
