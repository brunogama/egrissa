# Egress Runtime Roadmap

- M0: Semantic kernel (complete).
- M1: Fake end-to-end runtime (complete).
- M2: SOCKS5 reference adapter (not started).
- M3: HTTP CONNECT adapter (not started).
- M4: Relay protocol (not started).
- M5: MASQUE (not started).
- M6: Provider adapters (not started).
- M7: Observation-driven route intelligence (not started).

M1 is the required gate before real networking. Start real network I/O in M2.
