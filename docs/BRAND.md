# Egrissa Brand Guide

**Working commercial name:** Egrissa

**Tagline:** Govern every route. Preserve every boundary.

---

## Why Egrissa

Egrissa is a coined name derived from "egress" without describing a narrow protocol, a provider, or an IP-management product. It fits a runtime that governs how workloads leave a network while keeping identity, route, observation, and verification as distinct facts.

The name is short, pronounceable, and works across the product family:

- **Egrissa Runtime** - the Rust orchestration runtime.
- **Egrissa Relay** - a managed relay offering, if one is later built.
- **Egrissa Verify** - evidence-backed egress verification, if offered separately.

The public product name should be **Egrissa**. Use **Egrissa Runtime** where protocol or package-level precision matters.

---

## Collision check and clearance

A web search on October 19, 2026 found `Egrissa` used primarily as a game-character name, surname, and clothing-model name. It did not identify a directly competing networking or egress-orchestration product. That is only an initial collision screen, not a trademark opinion or clearance.

Before public launch, an authorized owner should:

1. Search relevant trademark registers in every planned market and class.
2. Check company registrations, package registries, domains, and major social handles.
3. Obtain counsel's approval before asserting trademark rights or using `®`.
4. Register the selected mark and relevant domains if available.

Until that work is complete, write the name as **Egrissa**, without `™` or `®`.

---

## Voice and positioning

Egrissa is infrastructure for teams that need egress decisions to be explainable and policy-bound. It is not an anonymity product, an IP-rotation service, or an access-control-circumvention tool.

Prefer:

- "Policy-driven network identity and egress orchestration"
- "Evidence-backed route decisions"
- "Fail closed when policy cannot be satisfied"
- "Logical identity, not an IP address"

Avoid:

- "Anonymous browsing"
- "Guaranteed IP continuity"
- "Bypass restrictions"
- "Undetectable rotation"
